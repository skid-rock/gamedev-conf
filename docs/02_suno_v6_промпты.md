# Suno v6 — как писать промпты

Разведка по сети от 11.09.2026, через два дня после релиза v6 (09.09.2026). Доступ — веб-интерфейс.

Отзывы о v6 и способы обойти её слабости, собранные 17.09.2026, — файл [15](15_suno_v6_отзывы_и_обходы.md).

Маркеры достоверности:
- **[офиц]** — блог Suno, help center, release notes.
- **[сообщ]** — гайды и тесты сообщества. Часть написана по v5.5 и в v6 не перепроверена.
- **[не проверено]** — гипотеза, нужен собственный прогон.

Важно: почти все гайды по промптам в сети написаны под v4–v5.5. Эти модели с 09.09 недоступны, проверить советы на них нельзя. Что из старого переносится в v6 — выясняем только своими тестами.

## 1. Что изменилось в v6

### Три модели [офиц]

| Модель | Кому | Описание Suno |
|---|---|---|
| v6 | Pro, Premier | «Balanced, expressive», надёжная, предсказуемая. Когда знаешь, что хочешь получить |
| v6-wild | Pro, Premier | «Leans into unexpected choices, genre-blending, results that push further from the prompt» |
| v6-mini | все, включая Free | быстрая и лёгкая, для набросков и массовой генерации |

- Все три — до 8 минут на генерацию [офиц].
- Стоимость та же: 10 кредитов за пару треков [офиц]. Max Mode дороже, нужен для длинных треков, Cover, style transfer и стабильности на протяжении трека [офиц].
- Модели v3.5–v5.5 отключены. Старые треки остаются в библиотеке, Cover/Extend по ним работают уже на v6 [офиц].
- Custom Models и Voices, обученные на v5.5, автоматически переведены на v6 [офиц].

Для нашего проекта: v6 — рабочая лошадка для главной темы, лаунжа, эмбиента. v6-wild — для направления «этника × электроника», где как раз нужен непредсказуемый результат. v6-mini — для быстрой проверки формулировок, прежде чем тратить кредиты на v6.

### Новые возможности [офиц]
- Правка части готового трека обычным языком: «change the chorus so it's sung by a gospel choir». Остальное сохраняется.
- Правка одного слова или строки в тексте без перегенерации.
- Мэшап из нескольких источников в одном запросе: «take the vocals from x, drums from y».
- Сэмплирование: «sample the riff at 0:45, isolate the guitar, build a beat around it».
- Мультимодальный ввод: текст, аудио, картинки, видео. Можно кинуть постер конференции как референс [не проверено, как именно влияет].
- Заявление Suno: модель «understands more of the language and building blocks musicians use, from vocals, instrumentation and structure to mood, references». То есть словарь музыканта читается лучше.

### Панель Create в v6 [сообщ, по обзорам первого дня]
- Выбор модели — дропдаун справа вверху формы Create [офиц].
- Advanced Mode: Vocal Gender, Duration (Custom / Auto), Max Mode (тумблер), слайдеры Weirdness, Style Influence, Variety, тумблер Personalize / My Taste.
- Лимиты полей не изменились: Style — 1000 символов, Lyrics — 5000 [сообщ, замер счётчика в интерфейсе].

## 2. Устройство промпта

Три места, куда пишем:

1. **Style** — общий звук трека: жанр, настроение, инструменты, продакшн, темп.
2. **Lyrics** — текст плюс метатеги в квадратных скобках. Управляют конкретными моментами: секции, входы инструментов, подача.
3. **Exclude Styles** (в Advanced) — чего не должно быть.

### Поле Style

Порядок элементов [сообщ, сходятся несколько источников]:

```
жанр/поджанр → настроение и энергия → инструменты → продакшн → темп (BPM)
```

Для вокальных треков между настроением и инструментами добавляют характер вокала.

- Первые слова весят больше остальных. Жанр и настроение — в начало, не после абзаца описаний [сообщ].
- Объём: по одному источнику 4–7 дескрипторов, по другому 8–15 тегов. Сходятся в одном: меньше 4 — модель заполняет пробелы шаблоном, больше ~15 — дескрипторы конкурируют и звук мутнеет [сообщ].
- BPM указывать всегда: держит грув и не даёт жанру уплыть [сообщ].
- Противоречивые теги («calm» + «energetic») — выбрать одно направление [сообщ].
- Отрицания в Style не работают: «no vocals» в поле Style модель может прочитать как инструкцию про вокал. Отрицания — только в Exclude [сообщ, проверено на v5.5 и на v6 в первый день].
- Имена артистов: запросы «sing like X» отклоняются из-за лицензий. Описывать звук, а не имя: эпоха, вокал, инструменты, продакшн, темп [сообщ]. Названия игр и OST как референс («Shovel Knight OST style») — [не проверено], в гайдах примеров нет. Стоит протестировать: в наших промптах это главный инструмент.

### Поле Lyrics и метатеги

- Надёжные структурные теги: `[Intro]`, `[Verse]`, `[Pre-Chorus]`, `[Chorus]`, `[Bridge]`, `[Instrumental Break]`, `[Solo]`, `[Outro]`, `[End]` [сообщ].
- Теги — вероятностные подсказки, не команды. Модель следует им чаще всего, но может проигнорировать [сообщ].
- Ключевое наблюдение по v6 [сообщ, тест первого дня]: модель читает описание подачи внутри тега секции. Пример вида `[Verse | whispered, intimate]` реально влиял на результат, хотя в Style этого не было. То есть параметризованные теги стали рабочим инструментом.
- «`[Intro]` — такая же секция, как и другие: если написать про певца, получишь певца». Для инструментала в тег пишем, какой инструмент входит, а не оставляем пустым [сообщ].

### Инструментал

Три рычага одновременно [сообщ]:
1. Тумблер **Instrumental** в Custom Mode.
2. В Lyrics — только структурные теги без слов: `[Intro: soft pads]`, `[Build]`, `[Drop]`, `[Outro]`. Lyrics становится таймлайном.
3. В **Exclude Styles** — `vocals, singing, lyrics` для страховки.

Слова «no vocals» в Style — не писать (см. выше про отрицания).

### Слайдеры [сообщ]

| Слайдер | Что делает | Как ставить |
|---|---|---|
| Style Influence | насколько буквально читается Style. Дефолт 50% | для точного промпта — 70–100%. На 50% «половина промпта отбрасывается до первой ноты». Первое, что крутить, если результат generic |
| Weirdness | насколько вероятны музыкальные решения. Независим от Style Influence | 20–40% для «безопасных» треков, выше — для этники |
| Variety | новый в v6, дефолт Normal. Насколько два трека одной генерации расходятся между собой | ставить 0, если нужен полный контроль. Замечание тестеров: разброс между двумя треками одной генерации бывает больше, чем эффект правки промпта. Поэтому А/Б-тест промптов на Variety Normal ничего не покажет |
| Max Mode | дороже, стабильнее на длинных треках и Cover | включать для главной темы и Cover-цепочки |

### Длительность

- v6: до 8 минут, в Advanced — Duration Custom / Auto [офиц].
- На v5.5 слайдер шёл от 10 секунд до 6 минут с шагом 5 [сообщ]. Диапазон в v6 [не проверено].
- Длительность — цель, не гарантия. Секунда в секунду не получится, короткие вещи дорезаются в редакторе [сообщ].

## 3. Короткие треки и джинглы [сообщ]

Отдельная техника. Главное — не просить длину, а убрать из промпта всё, что запускает «песенную» структуру.

Ключевые фразы в Style, по убыванию важности:
1. `no verse, no chorus` — запрещает песенную форму. (Это единственное отрицание, которое источник рекомендует именно в Style. Конфликтует с правилом «отрицания только в Exclude» — [не проверено], что победит в v6.)
2. `single musical phrase` — одна фраза, и конец.
3. `broadcast bumper` / `logo sting` / `station ID` — модель воспринимает как звуковой элемент, а не как музыку.
4. `instant impact, no intro build-up` — без раскачки.

Что ломает джингл: `cinematic`, `epic`, `dramatic` (запускают киношное развитие), `build-up`, `rising intro`, `verse`, `chorus`, `hook`, `emotional vocal`.

Шаблон из источника:

```
Ultra short logo jingle, clean modern sound, instant impact, no intro build-up,
no verse, no chorus, single musical phrase, broadcast bumper, usable 5-12 seconds, clean ending hit
```

Для нас это значит: черновой промпт джингла в файле 01 (`short 8-bit orchestral sting, triumphant, 6 seconds`) содержит сразу два триггера длинной формы — «triumphant» близок к «epic», и нет запрета на структуру. Надо переписать.

Альтернатива джинглу с нуля: сгенерировать главную тему и вырезать мотив из неё в редакторе. Так мотив гарантированно совпадёт.

## 4. Cover, Persona, Custom Model — для цепочки «одна тема в разных стилях»

- **Cover** сохраняет мелодию и текст, меняет аранжировку по новому Style. Вызов: под треком ⋮ → Remix/Edit → Cover [сообщ, v4.5–v5.5; в v6 Cover заявлен официально, интерфейс [не проверено]].
- **Persona** сохраняет тембр и подачу, но «не сохраняет мелодические паттерны, фразировку, ритм» [сообщ]. Для инструментальной темы Persona бесполезна, нужен именно Cover.
- **Custom Model** — своя модель на своих треках, переведена на v6 [офиц]. Вариант на потом: обучить на 5–10 удачных треках конференции, чтобы новые генерации держали фирменный звук.
- Для Cover рекомендуют Max Mode [офиц: «maintaining consistency throughout tracks»].
- Правка обычным языком в v6 («make the bridge lofi») — [не проверено], сохраняет ли мотив лучше, чем Cover. Проверить на одном треке.

## 5. Что пересмотреть в наших черновых промптах (файл 01)

Разбор по правилам выше, без переписывания — переписываем после первых тестов.

| Промпт | Проблема | Что менять |
|---|---|---|
| Главная тема | «instrumental» отсутствует, порядок ок | тумблер Instrumental, Max Mode, Style Influence 80%+, структура в Lyrics тегами |
| Джингл | «6 seconds» и «triumphant» запускают длинную форму | техника из раздела 3 или вырезать из темы |
| Lounge | «instrumental» в конце Style — отрицание-подобный тег | убрать из Style, тумблер + Exclude |
| Перебивка | 20–30 сек — короткая форма, промпт песенный | Duration Custom + теги `[Hook]`, `[Tag]`, минимум секций |
| Party | ок | тумблер Instrumental |
| Фирменный | ок, самое место для v6-wild | Weirdness 60%+, несколько прогонов |
| Эмбиент | нет BPM | добавить темп (60–70) и длительность 5–8 мин |

Общее для всех: убрать слово «instrumental» из Style, ставить тумблер; референсы на игры проверить отдельным тестом.

## 6. Протокол тестов

Цель первого раунда — не получить треки, а выяснить, как v6 читает наши формулировки. Один трек на v6-mini стоит столько же, сколько на v6 (10 кредитов за пару), так что для проверки формулировок разницы в цене нет; mini быстрее.

Настройки для всех тестов: Variety = 0 (иначе разброс двух треков забивает эффект промпта), Style Influence = 80%, Weirdness = 30%.

| # | Что проверяем | Промпт A | Промпт B | Оценка |
|---|---|---|---|---|
| 1 | Референс на игру читается? | `...chiptune orchestral, Shovel Knight OST style` | тот же без референса | стало ли ближе к референсу |
| 2 | Отрицание в Style | `lofi chiptune, no vocals` без тумблера | тумблер + Exclude `vocals` | появился ли вокал |
| 3 | Джингл | шаблон из раздела 3 | черновой промпт из файла 01 | длина, есть ли конец |
| 4 | Параметризованные теги | Lyrics: `[Intro: solo game boy lead]` `[Build: strings enter]` | Lyrics пустой | соблюдён ли порядок входов |
| 5 | Cover держит мотив? | главная тема → Cover со Style лаунжа | тот же Style с нуля | узнаётся ли мотив |
| 6 | v6 vs v6-wild на этнике | один промпт, v6 | тот же, v6-wild | интереснее ли результат |

Формат записи результата: номер теста, модель, полный промпт, ссылка на трек, оценка 1–5, одна фраза что не так.
