# Терминология электронной музыки — справочник

Зачем: чтобы описывать, что и в каком месте трека слышно, одним языком — в заметках по эталонам из `../music/gamepush/`, в
метатегах Suno (файл 02) и в промптах альбома (файл 07). Термины общие для клубной электроники, примеры — из DnB, потому
что альбом на базе jump-up.

Устройство: сначала **слои** (что звучит одновременно), потом **секции** (что происходит во времени), потом слуховые
подсказки для пар, которые легко спутать, и шаблон разбора трека.

## 1. Слои — что звучит одновременно

Трек в любой момент — это несколько слоёв поверх друг друга. Внизу бас и бочка, посередине аккорды и ритм, сверху
мелодия и эффекты. Когда описываешь звук, полезно сначала назвать слой, а потом характер: «лид — писклявый квадрат»,
«бас — квакающий wobble».

### Низ

| Термин | Что это | Как звучит | В наших промптах |
|---|---|---|---|
| **Бас (bass)** | низкий голос трека. В jump-up — главный герой, несёт хук | гудит, качает, «разговаривает» | `wobbling talking bass riff`, `FM slap bass` |
| **Саб (sub)** | самая нижняя чистая часть баса, одна нота без обертонов | скорее чувствуется телом, чем слышится; на телефоне пропадает | отдельно не пишем, входит в `loud club mix` |
| **Мид-бас (mid bass)** | средняя, «рычащая» часть баса — то, что слышно на любых колонках | wobble (качание фильтра), reese (гудящий расстроенный хор), hoover (сирена-«пылесос»), talking (как будто произносит слоги) | `wobbling`, `talking`, `modulated` |
| **Кик (kick)** | бочка, удар на сильную долю | глухой толчок | внутри `two-step breakbeat` |

### Середина

| Термин | Что это | Как звучит | В наших промптах |
|---|---|---|---|
| **Пэд (pad)** | длинные тянущиеся аккорды на заднем плане. Не мелодия, а «воздух» и настроение | ровный слой, без атаки, может звучать целый такт и дольше | `soft pads`, в jump-up почти нет |
| **Стаб (stab)** | короткий резкий аккордовый удар, как штамп | «бам» — и тишина | `arpeggiated chord stabs`, `FM brass stabs` |
| **Плак (pluck)** | короткая щипковая нота с быстрым затуханием | как струна или клавиша чиптюна | в чиптюне почти любая короткая нота — плак |
| **Арп (arp, арпеджио)** | аккорд, разложенный в быстрый повторяющийся рисунок нота за нотой | «переливы», характерная NES-фактура | `fast NES-style arpeggiated chord stabs` |
| **Рифф (riff)** | короткая повторяющаяся фраза, чаще у баса или гитары | одна и та же фигура на каждые 1–2 такта | `bass riff`, `harmonic minor riff` |
| **Хук (hook)** | самая запоминающаяся фраза трека, та, что «цепляет». Может быть у любого слоя | хочется напеть после первого прослушивания | в ядре альбома хук = бас, лид его дублирует |

### Верх

| Термин | Что это | Как звучит | В наших промптах |
|---|---|---|---|
| **Лид (lead)** | главный мелодический голос. Солист — обычно один | самый заметный высокий голос, ведёт мелодию | `8-bit square lead`, `FM lead` |
| **Мелодия (melody)** | то, что играет лид. Лид — инструмент, мелодия — ноты | | `lead plays the main melody` |
| **Вокал-чоп (vocal chop)** | нарезанный кусок голоса, используемый как инструмент, без смысла текста | слог, выкрик, «эй» на ударе | в инструментале не используем |

### Ритм

| Термин | Что это | Как звучит | В наших промптах |
|---|---|---|---|
| **Снэр (snare)** | малый барабан, удар на слабую долю (2 и 4). В DnB — второй по важности звук после баса | резкий щелчок или хлопок | `snappy snare` |
| **Хэты (hi-hats)** | тарелки, заполняют промежутки между кика и снэра | «тс-тс-тс» | внутри брейка |
| **Брейк (break, breakbeat)** | барабанная петля целиком, с характером. В DnB это ось стиля | amen — рваный, сэмплированный; two-step — простой «кик-снэр-кик-снэр»; roller — ровный, непрерывный | `two-step breakbeat`, `amen break`, `rolling drums` |
| **Грув (groove)** | ощущение качания от того, как бас и барабаны цепляются друг за друга | «качает» или «не качает» | `bass holds the groove` |
| **Снэр-ролл (snare roll)** | ускоряющаяся дробь снэра перед сменой секции | «тр-р-р-р-Р-Р-Р» | `snare roll` в конце брекдауна |
| **Филл (fill)** | короткое заполнение в последнем такте фразы: дробь, эффект, пауза. Сигнал «сейчас что-то сменится» | | `coin and 1-up sounds as fills` |

### Эффекты

| Термин | Что это | Как звучит |
|---|---|---|
| **Райзер (riser)** | нарастающий звук вверх по высоте и громкости перед дропом | шум или нота, которая «поднимается» |
| **Свип (sweep)** | фильтр, который открывается или закрывается по всему слою | звук «расцветает» или «глохнет» |
| **Импакт (impact)** | одиночный удар в точке дропа | взрыв, «бум» |
| **Даунлифтер (downlifter)** | звук вниз после удара, обратный райзеру | падающая сирена |
| **Атмосфера (atmos, texture)** | фоновый шум, поле, шипение винила, эмбиент | не музыкальный слой, а «воздух комнаты» |
| **SFX** | одиночные звуковые события | наши монетки, прыжки, лазеры, «stage clear» |

## 2. Секции — что происходит во времени

Секции считают **тактами**. В DnB фразы по 8, 16 и 32 такта, смены почти всегда на границе фразы.

| Темп | 1 такт | 8 тактов | 16 тактов | 32 такта |
|---|---|---|---|---|
| 170 BPM | 1,41 с | 11 с | 23 с | 45 с |
| 174 BPM | 1,38 с | 11 с | 22 с | 44 с |
| 176 BPM | 1,36 с | 11 с | 22 с | 44 с |

Таблица нужна, чтобы по времени в плеере прикинуть, на какой такт пришлась смена.

### Секции по порядку

| Секция | Тег в наших Lyrics | Что происходит | Обычная длина |
|---|---|---|---|
| **Интро (intro)** | `[Intro]` | вход: часто ровный бит без баса, чтобы диджей мог свести. У нас — аркадные SFX и намёк на мелодию | 16–32 такта |
| **Билдап (build-up)** | `[Build]` | напряжение растёт: райзер, снэр-ролл, фильтр открывается, часто пауза на долю перед самым ударом. Обещание дропа | 8–16 тактов |
| **Дроп (drop)** | `[Drop]` | вступают бас и полный бит. Кульминация, главная часть трека. Здесь живёт хук | 32 такта |
| **Свитч (switch, switch-up)** | `[Switch]` | поворот **внутри дропа**, обычно на 16-м такте: бас или ритм внезапно меняется на другой рисунок. Фирменный приём jump-up — «два баса в одном дропе» | второй половиной дропа |
| **Брекдаун (breakdown)** | `[Breakdown]` | сброс энергии после дропа: бас и бит уходят, остаются пэд, мелодия, атмосфера. Передышка перед вторым заходом. Часто заканчивается собственным билдапом | 16–32 такта |
| **Второй дроп (second drop)** | `[Drop]` второй раз | вариация первого: тот же хук, но другой бас, другие барабаны или добавлен слой. Обычно громче и плотнее | 32 такта |
| **Аутро (outro)** | `[Outro]` | выход: ровный бит без мелодии, зеркало интро. Для сведения следующего трека | 16–32 такта |

### Реже, но встречается

| Секция | Что это | Чем отличается от соседей |
|---|---|---|
| **Бридж (bridge)** | переходная секция с **новым материалом**, не похожая ни на то, что было, ни на то, что будет. В поп-музыке обязательна, в электронике встречается реже | брекдаун снимает энергию на том же материале, бридж уводит в сторону на новом. В Suno тег `[Bridge]` — из песенного словаря, для DnB надёжнее `[Breakdown]` |
| **Пре-дроп (pre-drop)** | последние 1–4 такта билдапа: тишина, одиночный голос, короткая фраза перед ударом | часть билдапа, не отдельная секция. Наш «хроматический пробег перед дропом» — как раз сюда |
| **Роллер (roller)** | не секция, а тип дропа: ровный непрерывный бит без свитчей и пауз, «катится» | характерен для dancefloor. Противоположность — jump-up с свитчами и стопами |
| **Дабл-дроп (double drop)** | диджейский приём: дропы двух треков сведены в одну точку | к структуре одного трека не относится |
| **Инструментал-брейк** | в песенной музыке — секция без вокала | в инструментале смысла не имеет, тег `[Instrumental Break]` в наших промптах не нужен |

### Схема типичного DnB-трека

```
такты:   0        16       32                 64        80                112       128
         |--------|--------|--------|--------|---------|--------|--------|---------|
секция:   интро    билдап   ДРОП     (свитч)  брекдаун  билдап   ДРОП 2   аутро
энергия:  ▁▁▁▂▂▂   ▃▃▄▄▅▆   ███████  ███████  ▂▂▂▁▁▁     ▃▄▅▆▇   ████████  ▅▄▃▂▁
```

На 174 BPM это около 3 минут. Suno секции ужимает или удлиняет по-своему, поэтому в разборе фиксируем реальное время.

## 3. Слуховые подсказки — как отличить

Пары, которые чаще всего путаются. По одному признаку на пару.

| Пара | Признак |
|---|---|
| **Лид или пэд** | лид меняет ноты часто и его хочется напеть; пэд держит одну гармонию долго, напеть нечего. Если убрать пэд — станет пусто, но мелодия останется. Если убрать лид — пропадёт мелодия |
| **Бас или лид** | бас внизу и его слышно телом; лид вверху. В ядре альбома они играют одно и то же — тогда ищи, какой из двух голосов **ниже**: это бас, а верхний повтор — лид |
| **Стаб или арп** | стаб — один удар аккорда целиком; арп — тот же аккорд, но рассыпанный на быстрые отдельные ноты. Стаб «бам», арп «трррл» |
| **Плак или лид** | плак — характер звука (короткий, щипковый), лид — роль (главный голос). Плак может быть лидом. Спрашивай «что делает», а не «как звучит» |
| **Свитч или второй дроп** | свитч — внутри дропа, бит не прерывался, поменялся только бас или ритм. Второй дроп — перед ним была передышка (брекдаун) и билдап |
| **Брекдаун или бридж** | брекдаун — знакомый материал стал тише и проще (тот же хук, но без баса и бита). Бридж — материал незнакомый, такого раньше в треке не было |
| **Брекдаун или интро** | звучат похоже. Признак — что было до: если ничего, это интро; если дроп — брекдаун |
| **Билдап или брекдаун** | направление энергии: билдап растёт (райзер, дробь, ускорение), брекдаун падает или стоит на месте. Брекдаун часто заканчивается билдапом — граница там, где энергия развернулась вверх |
| **Two-step или amen** | two-step — ровный «кик-снэр-кик-снэр», можно отстукивать пальцем; amen — рваный, с перебивками, снэры «спотыкаются» |
| **Roller или jump-up дроп** | roller катится без остановок 32 такта; jump-up останавливается, дёргается, меняет бас на середине |
| **Райзер или свип** | райзер идёт вверх по высоте (звук «поднимается»); свип — фильтр открывается, звук «расцветает» на месте, высота та же |
| **Филл или свитч** | филл — один такт, потом всё как было или началась новая секция; свитч — новый рисунок держится дальше |

Общий приём: **слушать по одному слою за раз**. Первый проход — только бас. Второй — только барабаны. Третий — верх.
Так на слух выделяется структура, которую в общей массе не поймать.

## 4. Шаблон разбора трека

Для заметок по эталонам из `../music/gamepush/` и по кандидатам в альбом. Одна таблица на трек. Время — из плеера, такты — по
таблице темпа из раздела 2.

```markdown
### <название> — id `<suno id>` — <темп> BPM

| Время | Секция | Бас | Барабаны | Верх | Событие |
|---|---|---|---|---|---|
| 0:00 | интро |  |  |  |  |
| 0:22 | билдап |  |  |  |  |
| 0:44 | дроп |  |  |  |  |
| 1:06 | свитч |  |  |  |  |
| 1:28 | брекдаун |  |  |  |  |
| ... |  |  |  |  |  |

Хук: <какой слой и где впервые>
Сильнее всего: <секция и почему>
Слабее всего: <секция и почему>
Взять в промпт: <формулировка для Style или тега>
```

Как заполнять:

- **Секция** — из словаря раздела 2. Если непонятно, что это, пишем два варианта через `/` и признак, по которому не
  разобрались. Это тоже результат.
- **Бас / Барабаны / Верх** — по одному-два слова из раздела 1: `wobble`, `two-step`, `квадратный лид дублирует бас`,
  `пусто`.
- **Событие** — что произошло на границе: `снэр-ролл`, `stage clear фанфара`, `стоп на долю`, `монетка`.
- **Взять в промпт** — самое ценное поле. Формулировка сразу на английском, в словаре файла 02, чтобы переносить
  без перевода.

Пример заполненной строки:

```
| 0:44 | дроп | wobble, «разговаривает», 2 такта на фигуру | two-step, снэр сухой | квадратный лид дублирует бас | импакт + монетка на первой доле |
```
