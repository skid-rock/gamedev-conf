## 1. Почему переходы звучат криво

Проверено 16.09.2026 по библиотеке, логам и настройкам Mixxx, по sidecar-json и замеру `bpm-detect`. Установлен
Mixxx 2.5.6. Его настройки и база лежат в песочнице macOS:
`~/Library/Containers/org.mixxx.mixxx/Data/Library/Application Support/Mixxx/` — там `mixxx.cfg`,
`mixxxdb.sqlite` и логи `mixxx.log*`.

1. **Темп в Mixxx неверный у 25 из 28 jump-up треков.** Реальный — 171–180 BPM, а в библиотеке стоит 114–119
   (две трети) или 88 (половина). Эти значения выдал сам анализатор Mixxx, `qm-tempotracker`. Таблица правки —
   раздел 8.
2. **Неверный темп попал и в теги файлов, и записал его Mixxx.** В `mixxx.log.5` за 13.09, 21:25: у J3-1a старые
   метаданные `bpm: Bpm(Invalid)`, новые `bpm: Bpm(88.5)`, дальше `Exporting track metadata into file`. Экспорт
   тегов включён: `SyncTrackMetadataExport 1` (`mixxx.cfg:347`). Теги `initialkey` и `replaygain_track_gain`
   в файлах тоже от Mixxx. Через эти теги неверный темп увидел и REAPER.
3. **Auto DJ темп не подгоняет.** В `src/library/autodj/autodjprocessor.cpp` ветки 2.5 нет обращений к sync,
   quantize, bpm и beat: Auto DJ только запускает деку и ведёт кроссфейдер. Фазу при старте деки выравнивает
   Quantize (`src/engine/enginebuffer.cpp:776–787`, `requestSyncPhase()`). Темп выравнивает только Sync,
   включённый на деках, а с неверным BPM он растягивает трек не туда. Включался ли Sync при прошлых попытках,
   по логам не видно.
4. **Не тот режим перехода, и меток почти нет.** В `mixxx.cfg:10` стоит `TransitionMode 1`, то есть Fade At
   Outro Start. Значения по `autodjprocessor.h:166–171`: 0 — Full Intro + Outro, 1 — Fade At Outro Start,
   2 — Full Track, 3 — Skip Silence. Файлы 09 и 00_формат планировали Full Intro + Outro. Метки jump-up в базе:

   | Метки | Треков |
   |---|---|
   | нет ни Intro End, ни Outro Start | 16 |
   | только Outro Start | 8 |
   | только Intro End | 1 |
   | обе | 3 |

   Без меток Auto DJ берёт время из поля: `Transition 10` (`mixxx.cfg:9`). Выходят десять секунд двух
   несведённых брейкбитов.
5. **Переходу не из чего собраться.** По полю `prompt` в sidecar-json у 24 из 28 треков структура кончается на
   `clean stop`, `stop dead` или `explosion`. Аутро из одних барабанов есть только у группы J5
   (`drums roll alone, 8 bars`). Интро без барабанов — у группы J4 и у J2-6, J2-7a. Поэтому любое наложение
   полных частей — это два дропа и два баса сразу.
6. **Темп в самих треках держится.** По `bpm-detect`: 17 ровных, 8 «поплывёт к концу», 3 «уедет, нужна
   карта» — J4-3a, J4-8b, N1-6a. Эти три для переходов с наложением не берём.
7. **J1-2a в Mixxx потеряется.** На диске файл уже называется `SkidRock - J1-2a - 175.m4a`, а в базе Mixxx
   остался старый путь `SkidRock - J1-2a.m4a`. Трек нужно добавить заново и заново поправить ему BPM.

## 2. Компромиссы

| Слот | Как играть | Нужно ли сводить |
|---|---|---|
| Дневные блоки, 12:00–20:30 | подряд, кроссфейд 2–4 с, Sync выключен | нет |
| Афтепати, synthwave | кроссфейд 4–8 с или мост на стемах | желательно |
| Афтепати, jump-up | «альбомом» или мост на стемах | да |

Уступки, которые почти не слышны:

- три трека с уезжающим темпом убрать;
- все треки блока заранее растянуть к одному темпу: сетки совпадут, и Sync почти не понадобится;
- каждый блок записать в файл заранее и на площадке играть файл. Страховочная запись нужна в любом случае,
  файл 09 §6.

Режим Auto DJ один на все плейлисты. При смене блока его придётся переключать вместе с очередью, файл 09 §7.

## 3. Рецепты

### Рецепт 0. «Альбом» — без подготовки, для jump-up

Треки написаны с интро и чистой концовкой, поэтому могут идти друг за другом.

- Auto DJ: Skip Silence, время перехода 0–1 с, Sync выключен.
- Наложения нет, так что темп не важен.
- Звучит как альбом, а не как DJ-сет, зато не криво.

При нуле секунд Auto DJ переключает треки встык: следующий стартует с первого звука, как только у текущего
кончился последний (`useFixedFadeTime`, ветка `else`).

### Рецепт 1. «Радио» — для дневного фона

Skip Silence, время перехода 2–4 с, Sync выключен. Громкость выравнивает ReplayGain, он включён
(`mixxx.cfg:465`).

### Рецепт 2. «Мост на стемах» — для афтепати

Каждый трек превращается в DJ-версию:

```
[16 тактов: только мелодия] [трек без финальной остановки] [16 тактов: только барабаны]
```

Под мелодию входящего трека 16 тактов звучат только барабаны уходящего. Барабаны не спорят с мелодией ни по
тональности, ни по ритму, а бас в этот момент звучит максимум один. Дроп входящего вступает, когда уходящий
кончился.

Сборка:

1. Все треки блока растягиваются к одному темпу. Для DnB — 174.545 BPM: на нём 16 тактов длятся ровно 22 с.
   Для synthwave — 120 BPM, там 16 тактов ровно 32 с.
2. Стемы разделяет Demucs (раздел 5). Без локальной установки можно взять Split from Mix в Suno Pro: одна
   дорожка плюс всё остальное, по справке 10 кредитов за извлечение. Считается ли это в лимит скачиваний,
   справка не говорит.
3. Интро — стем без барабанов и баса из начала дропа. Если у трека уже есть интро без барабанов, берётся оно.
4. Аутро — стем барабанов из последних 16 тактов перед остановкой.
5. Mixxx: Full Track, время перехода 22 с (для synthwave — 32 с), Quantize и Sync на обеих деках. Метки не нужны.

Метки не нужны вот почему. В режиме Full Track Auto DJ ставит следующий трек с начала (`startPoint = 0.0`)
и начинает затухание за заданное время до конца файла (`useFixedFadeTime`). Поле времени принимает только
целые секунды (`dlgautodj.cpp:203`, `static_cast<int>`), поэтому темп и подобран под ровные секунды.

Вручную в REAPER это около 30 переходов — по прикидке, день работы. Скрипт делает то же за минуты.

### Рецепт 3. «Готовый файл»

Скрипт из рецепта 2 сам сводит блок в WAV и выдаёт список треков с таймкодами. На площадке остаётся нажать Play
в любом плеере. Этот же список пригодится для письма организатору, legal/02 §3.

## 5. Техзадание на скрипт `dj-edit`

Каталог — `scripts/dj-edit/`. Язык — Python, потому что Demucs написан на нём. Запускать из окружения
StemDeck или из отдельного — решить на этапе 2.

**Что уже есть на машине** (проверено 16.09.2026):

- Apple M4 Pro, 24 ГБ, macOS 26.6.2.
- `ffmpeg` 9.0.1 из Homebrew, фильтра `rubberband` в нём нет.
- `rubberband` 4.0.0 — бутылка в Homebrew есть, не установлен.
- Системный `python3` — 3.14.7. `uv` не установлен.
- StemDeck 0.8.0-alpha.4. Его окружение: `~/Library/Application Support/StemDeck/runtime/python/bin/python3.12`,
  в нём demucs 4.0.1, torch 2.6.0, torchaudio 2.6.0, numpy, scipy, librosa 0.11.0, soundfile, openunmix.
  Модели нет: в `config.json` стоит `modelReady: false`, папка `models` пуста. Там же `torchDevice: mps`, но по
  сторонним данным Demucs на MPS не работает из-за комплексных тензоров — держать запасной вариант на CPU.
  [не проверено]
- Актуальный Demucs развивается в форке `adefossez/demucs`.

**Входы:**

- m4a из `jump-up/` (48 кГц, стерео) и sidecar-json рядом;
- порядок треков — список или m3u-экспорт плейлиста из Mixxx;
- темп и первая доля — `bpm-detect --min 150 --max 200 --json out.json *.m4a`.

**Шаги на трек:**

1. Растянуть к целевому темпу через `rubberband`. Флаги сверить с `rubberband --help`.
2. Разделить на стемы drums, bass, other. Стем vocals у инструментала пустой.
3. Найти дроп по громкости баса в каждом такте: дроп — первый такт с резким ростом баса. Этот такт считать
   «единицей».
4. Найти конец — последний полный такт перед остановкой.
5. Собрать: 16 тактов стема other из начала дропа (или готовое интро без барабанов) + тело от дропа до конца
   + 16 тактов стема drums перед концом. На стыках — фейды в несколько миллисекунд, чтобы не щёлкало.
6. Сохранить в WAV или FLAC. Файл начинается ровно на сильной доле, без тишины, длина — целое число тактов.
   У AAC есть задержка кодера, и не каждый декодер её срезает, поэтому m4a на выходе не берём.
7. Записать тег BPM = 174.545. Как Mixxx 2.5 обходится с тегом BPM при анализе нового файла, не проверено —
   проверить на первом файле. Запасной путь — Change BPM или ручной ввод.

**Параметры:**

| Что | Значение |
|---|---|
| Целевой темп, DnB | 174.545 BPM = 3840 / 22; 16 тактов = 22 с, 8 тактов = 11 с |
| Целевой темп, synthwave | 120 BPM; 16 тактов = 32 с |
| Режим Auto DJ | Full Track (`TransitionMode 2`), время = длина моста в целых секундах |
| Деки | Quantize и Sync на обеих |
| Исключить | J4-3a, J4-8b, N1-6a |
| Готовое интро без барабанов | группа J4, J2-6, J2-7a — по `prompt`, на слух не проверено |
| Готовое аутро из барабанов | группа J5, 8 тактов |

**Выход:** `mix/edits/<код>.wav` и отчёт по каждому треку: исходный темп, коэффициент растяжки, найденные дроп
и конец, длина.

**Проверка:**

- щелчки по сетке в начале и в конце edit-файла: `bpm-detect --click`, для конца — `--click-from`;
- прогон пары треков в Mixxx на слух.

| Pixabay | бесплатно | коммерческое использование разрешено, продавать и распространять трек как есть нельзя; о публичном исполнении прямо ничего не сказано | DnB — около 72 страниц, в основном короткие стоковые треки |

Не подходят:

- **Uppbeat** — лицензия покрывает видео на YouTube, TikTok и Instagram. Для показа на живом мероприятии нужна
  другая лицензия, её оформляют через форму поддержки.
- **NCS** — бесплатно для авторов контента на YouTube и Twitch.
- **StreamBeats** — стримы, видео, подкасты; ремиксы и производные работы запрещены.
- **Epidemic Sound** — мероприятия только по индивидуальному плану.
